순서: **① 쓴 돈·다녀온 한마디 (완료) → ② 당일치기·차로 가는 여행 (완료) → ③ 골프장 (만듦, 2026-10-19) · 운동시설은 나중에 → ④ 사용자 피드백 반영 (2026-10-22)**

## ④ 사용자 피드백 반영 (2026-10-22) — 숙소 기준·직접 넣기·카카오 장소 추가·길찾기·공유 화면

피드백 6개와 처리:

| # | 피드백 | 처리 |
| --- | --- | --- |
| 1 | 식당·카페·볼거리 말고 직접 넣기 (해변에서 놀기, 근처 사진) | **만듦.** 슬롯 `custom: { name, address?, lat?, lng? }`. S03 「+ 직접 넣기」, 장소 선택 시트 맨 아래 「직접 넣기」. 위치는 골라도 되고 안 골라도 됨 (없으면 시간만 차지) |
| 2 | DB 에 없는 식당·카페 → 검색해서 찾고 저장 | **만듦.** 장소 선택 시트에서 검색어가 있으면 카카오 로컬 검색 결과를 아래에 붙인다. 고르면 `wooz_trip_places` 에 `source_provider='kakao'`, `status='candidate'` 로 저장 → 그 여행에서 바로 쓰고, 운영자가 승인하면 모두에게 보인다. 영업시간·휴무는 없음 |
| 3 | 숙소를 기준점으로 (지금은 공항 기준이라 멀다) | **고침.** 원인: 숙소를 글자로만 받아 `stay_lat/lng` 가 늘 비어 있었다. S02·여행 정보 수정·복사 시트에서 카카오 검색으로 숙소를 고르면 좌표 저장 → 숙소 칸이 위치를 갖고, 둘째 날부터 거리순·이동시간·지도가 숙소에서 시작 |
| 4 | 카카오·네이버 길찾기, 실제 시간·거리 | **1단계 만듦**: 결과·공유 화면 이동 구간마다 「길찾기」(카카오맵 링크, API 호출 없음). 화면 안 이동시간은 아직 직선거리 추정 → 2단계: 길찾기 API(카카오모빌리티 등) 요금 비교 후 `travel.js` + `wooz_trip_travel_cache` |
| 5 | 공유 화면을 더 자세히 / 같이 고치기 | **1단계 만듦**: 숙소, 칸별 시간대(10:00–12:00), 일자별 장소 수·이동·쓴 돈, 길찾기, 직접 넣은 일정, 고정 칸 메모. **2단계(같이 고치기)** 는 새 테이블(`wooz_trip_trip_members`) + RLS SQL 필요 → 범위 확인 후 |
| 6 | AI 추천도 숙소 기준 | **만듦.** 빈칸 채우기는 숙소 좌표로 자동 숙소 기준. 미리 만든 루트 고르기는 숙소에서 넣을 장소까지 평균 거리(km)만큼 감점(최대 40, `stayPenalty`) |

- 카카오 검색 (`src/lib/kakao.js`, `src/app/actions/places.js`): 서버에서 `KAKAO_REST_API_KEY` 로 키워드 검색 → 없으면 주소 검색. 로그인 사용자만.
  저장할 때는 화면이 보낸 값을 믿지 않고 이름·좌표로 다시 검색해 같은 카카오 ID 인지 확인한다. 이벤트 `place_added`.
- 카카오로 넣은 후보 장소는 승인 목록(공개 RLS)에 없어서 `getPlaceMap`·저장 검사·AI 채우기가 service_role 로 읽는다 (제외된 장소는 안 됨).
- **Vercel 에 `KAKAO_REST_API_KEY` 가 있어야** 숙소·장소 검색이 된다 (없으면 화면에 「카카오 검색 키가 아직 없어요」).
- 저장 결정: 카카오 검색 결과(이름·주소·좌표·전화·카카오 장소 링크)는 우리 DB 에 저장한다 (2026-10-22 사용자 결정). 리뷰·사진·별점은 여전히 저장하지 않는다. 정식 오픈 전 법률 확인 목록에 카카오 로컬 API 약관을 넣는다.

## ① 쓴 돈 · 다녀온 한마디 — 만듦

- 저장: `wooz_trip_trip_logs` (`supabase/migrations/0006_wooz_trip_trip_logs.sql`). `trips.days` 에 넣지 않는다
  (공개 루트는 누구나 days 를 읽을 수 있어서, 작성자가 고를 때만 보이게 하려고).
- S05: 여행 첫날부터 장소마다 「+ 쓴 돈·한마디」(금액 · 좋았어요/보통/별로 · 한마디 100자), 「그 밖에 쓴 돈」(항공·렌터카·숙소 등),
  마지막 날부터 「다녀오셨나요?」(최고예요~별로 5단계 + 한마디 300자). 일자별·전체 합계.
- 공개(S06)·가족 공유 링크: 자랑하기 시트에서 「쓴 돈·다녀온 한마디도 같이 보여주기」를 체크했을 때만 보인다. 복사할 때 기록은 따라가지 않는다.
- 슬롯의 장소가 바뀌면 그 슬롯의 옛 기록은 안 보이고 다음 저장 때 지워진다 (`src/lib/triplog.js`).
- 이벤트: `trip_reviewed` (만족도를 처음 남김).
- 나중에: 장소별 평균 지출·만족도를 운영자 화면에서 보기. 사용자 화면에 통계를 보여주려면 개인정보 안내 + 법률 확인 먼저.

## ② 당일치기 · 차로 가는 여행 — 만듦 (2026-10-18)

- DB 컬럼 없음: 이동 방식은 첫 고정 칸 kind(`home_start` / `airport_arrive`)로 판단 (`tripMode`), 출발 지역은 `fixed.area`.
- `config.js`: `TRAVEL_MODES`, `DEPART_AREAS`(제주 3곳 + 수도권 12곳), `REGION_ZONE`(권역 → 출발 지역 묶음). 인천·경기 권역을 열 때 `REGION_ZONE` 에 `capital` 로 추가하면 기본이 차가 된다.
- 차 여행에서 `arrival_time` = 출발 시각, `departure_time` = 집에 오는 시각.
- 복사: `setTripEnds` 가 내 이동 방식에 맞게 첫 칸·끝 칸을 바꾸고, 도착 전 빈 칸은 빼고 장소 칸은 도착 뒤로 민다.
- 남은 것: 수도권 장소가 생기면 출발지 기준 당일치기 AI 루트 만들기.

### 처음 설계

- 인천·경기는 차로 가는 당일치기가 많다. 지금 `buildDays` 는 늘 「공항 도착 → … → 공항 출발」이다.
- S02 에 「어떻게 가요?」: 제주 기본 비행기, 인천·경기 기본 차.
- 차: 항공 시각 대신 **출발 지역(목록에서 고름) · 출발 시각 · 돌아오는 시각**. 집 주소는 받지 않는다 (사용자 결정).
  - 일정: 「OO 출발」 고정 슬롯 → 슬롯들 → 「OO 도착」 고정 슬롯. 여러 날이면 첫날 출발·마지막 날 도착, 사이는 숙소.
  - 출발 지역 목록 예: 서울 강남·강북·서부, 수원, 성남·분당, 인천, 고양·일산 … (대표 좌표 하나씩, config 로 관리)
  - fixed.kind 에 `home_start`·`home_end` 추가 (sanitizeDays·copyRoute·RouteMap 마커 같이 고침).
- AI 루트: 출발이 공항이 아닌 당일치기 루트를 따로 만든다 (`scripts/ai-routes`).
- 제주 당일치기(아침 비행기·저녁 비행기)는 지금 구조로 된다.

## ③ 골프 · 운동시설 — 골프장 만듦 (2026-10-19)

- 골프장만 신청함 (골프연습장업 15154975 은 신청 안 함). API: `https://apis.data.go.kr/1741000/golf_courses/info` (`serviceKey`, `pageNo`, `numOfRows`, `type=json`), 같은 공공데이터포털 키 `TOURAPI_SERVICE_KEY`.
- `scripts/golf/collect.mjs` (`npm run golf:collect`, `--dry` 는 DB 안 넣음) — 매일 `daily.cmd` 마지막 단계. 전국 653건 → 영업 중 골프장 404곳 (제주 29곳).
  - 한 골프장의 회원제·대중형·9홀 등록을 이름(법인명·괄호·CC/컨트리클럽·「제주」 뗀 것) 또는 300m 안으로 묶는다.
  - 좌표 EPSG:5174 → WGS84 (`proj4`, towgs84 한국 측지계). TourAPI 골프장 좌표와 90~170m 차이 (골프장 안).
  - 좌표 없는 등록은 뺀다 (제주: 아덴힐, 파라다이스골프장 → 필요하면 관리자 화면에서 직접 추가).
  - 후보로 넣고 운영자가 승인. 폐업·휴업으로 바뀌면 승인돼 있어도 제외로 돌린다.
- DB: `0007_wooz_trip_golf.sql` (category `golf`, source_provider `mois`).
- 일정: 슬롯 종류 `golf` (5시간). S03 「+ 골프 칸」 → 비어 있는 오전·점심 칸 대신 들어간다. 장소 선택은 골프장만.
