# 다음 기능 설계 (2026-10-18 사용자와 합의)

순서: **① 쓴 돈·다녀온 한마디 (완료) → ② 당일치기·차로 가는 여행 → ③ 골프·운동시설**

## ① 쓴 돈 · 다녀온 한마디 — 만듦

- 저장: `wooz_trip_trip_logs` (`supabase/migrations/0006_wooz_trip_trip_logs.sql`). `trips.days` 에 넣지 않는다
  (공개 루트는 누구나 days 를 읽을 수 있어서, 작성자가 고를 때만 보이게 하려고).
- S05: 여행 첫날부터 장소마다 「+ 쓴 돈·한마디」(금액 · 좋았어요/보통/별로 · 한마디 100자), 「그 밖에 쓴 돈」(항공·렌터카·숙소 등),
  마지막 날부터 「다녀오셨나요?」(최고예요~별로 5단계 + 한마디 300자). 일자별·전체 합계.
- 공개(S06)·가족 공유 링크: 자랑하기 시트에서 「쓴 돈·다녀온 한마디도 같이 보여주기」를 체크했을 때만 보인다. 복사할 때 기록은 따라가지 않는다.
- 슬롯의 장소가 바뀌면 그 슬롯의 옛 기록은 안 보이고 다음 저장 때 지워진다 (`src/lib/triplog.js`).
- 이벤트: `trip_reviewed` (만족도를 처음 남김).
- 나중에: 장소별 평균 지출·만족도를 운영자 화면에서 보기. 사용자 화면에 통계를 보여주려면 개인정보 안내 + 법률 확인 먼저.

## ② 당일치기 · 차로 가는 여행 — 설계만

- 인천·경기는 차로 가는 당일치기가 많다. 지금 `buildDays` 는 늘 「공항 도착 → … → 공항 출발」이다.
- S02 에 「어떻게 가요?」: 제주 기본 비행기, 인천·경기 기본 차.
- 차: 항공 시각 대신 **출발 지역(목록에서 고름) · 출발 시각 · 돌아오는 시각**. 집 주소는 받지 않는다 (사용자 결정).
  - 일정: 「OO 출발」 고정 슬롯 → 슬롯들 → 「OO 도착」 고정 슬롯. 여러 날이면 첫날 출발·마지막 날 도착, 사이는 숙소.
  - 출발 지역 목록 예: 서울 강남·강북·서부, 수원, 성남·분당, 인천, 고양·일산 … (대표 좌표 하나씩, config 로 관리)
  - fixed.kind 에 `home_start`·`home_end` 추가 (sanitizeDays·copyRoute·RouteMap 마커 같이 고침).
- AI 루트: 출발이 공항이 아닌 당일치기 루트를 따로 만든다 (`scripts/ai-routes`).
- 제주 당일치기(아침 비행기·저녁 비행기)는 지금 구조로 된다.

- 행안부 인허가 API 는 handoff 의 「인허가(폐업 표시)」와 같은 데이터라 한 번 붙이면 폐업 식당 표시에도 쓴다.
- 좌표가 EPSG:5174(Bessel TM)라 위경도로 바꿔야 한다. 영업시간·요금·예약 정보는 없다.
- 일정 구조: 18홀은 4~5시간 → 새 슬롯 종류 「골프」(예: 07:00~12:00) 필요. 친구끼리·부모님과 루트에서 쓴다.
- 카카오·네이버 검색 결과로 골프장을 모아 저장하지 않는다 (CLAUDE.md 9장).
